# TypeScript — Formation YouTube

Code source de la formation **TypeScript** disponible sur la chaîne YouTube **La Minute de Code**.

Cette formation permet d'apprendre TypeScript progressivement et de comprendre comment ajouter un typage solide à ses projets JavaScript.

## 📚 Au programme

- Introduction à TypeScript
- Installation et configuration
- Types primitifs
- Tableaux
- Objets
- Fonctions
- Interfaces
- Types personnalisés
- Union Types
- Generics
- Classes
- Enums
- Narrowing
- Typage avancé
- TypeScript avec JavaScript moderne
- Projets pratiques
